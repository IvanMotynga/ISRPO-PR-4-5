# Практическая работа №4-5 по ИСРПО
## Тема: Настройка работы системы контроля версий Git и Visual Studio

### Описание проекта
Учебный проект многомодульного консольного приложения на C# (.NET).
В репозитории реализованы:
1. Базовая форма авторизации в ветке `master`.
2. Модуль тестирования знаний в параллельной ветке `Addfunction`.
3. Моделирование и ручное разрешение конфликта слияния (Merge Conflict).
4. Настройка файла `.gitignore` для исключения служебных каталогов и артефактов Visual Studio (`.vs/`, `bin/`, `obj/`, `*.user`, `*.suo`).

### Структура проекта
- `Program.cs` — основной исходный код приложения.
- `.gitignore` — правила фильтрации служебных файлов.
